# 🌦️ Weather & Typhoon Tracker

A web-based weather dashboard with real-time weather information,
forecast data, interactive maps, and tropical cyclone tracking.

## 🌐 APIs & Data Sources

### 🌦️ Open-Meteo
Used for:
- Current weather
- Temperature
- Humidity
- Wind speed and direction
- Visibility
- Atmospheric pressure
- 7-day forecast

Website: https://open-meteo.com/

### 🌀 PAGASA
Used as the primary reference for:
- Philippine tropical cyclone information
- Tropical cyclone bulletins
- Storm warnings
- Typhoon-related information

Website: https://www.pagasa.dost.gov.ph/

### 🗺️ Leaflet
Used for:
- Interactive weather map
- Location markers
- Storm track visualization
- Map controls

Website: https://leafletjs.com/

### 🛰️ Esri World Imagery
Used as the satellite basemap for the weather map.

Website: https://www.arcgis.com/

### 📍 OpenStreetMap Nominatim
Used for reverse geocoding and converting coordinates
into location names.

Website: https://nominatim.openstreetmap.org/

## ⚠️ Data Accuracy

Weather information is retrieved from external weather services.
Tropical cyclone information should be verified against official
PAGASA bulletins and advisories.
